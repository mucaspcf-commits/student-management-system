# Student Management System

Educational Python command-line project for managing student records and grades.

## Run

Requires Python 3, with no external packages.

```sh
python student_management.py
```

## Features

- Add students with whole-number grades from 0 to 100
- View records and grade classifications
- Update student names and grades
- Remove records
- Reject duplicate names when adding students

All records are stored in memory and are lost when the program closes. The repository contains no preloaded student data.

Grade categories: Fail (0–49), Pass (50–64), Credit (65–74), Distinction (75–84), High Distinction (85–100).
